# Project File Box

業務フォルダ・ファイルのリンクを、プロジェクトごとに整理するWindowsアプリです。

## ダウンロード

[最新のWindows版をダウンロード](https://github.com/UtahArts/ProjectFileBox-Releases/releases/latest)

Windows x64向け、.NETランタイム同梱のポータブル版です。
`ProjectFileBox_1.3.0_Windows_x64.zip` を展開し、`app/ProjectFileBox.exe` を起動します。

## 主な機能

- フォルダ・ファイルをドラッグ＆ドロップしてプロジェクトごとに整理
- Windowsで現在開いている対応フォルダ・ファイルを一覧表示
- アイコン・一覧表示、検索、お気に入り、並べ替え、まとめて開く
- プロジェクト・登録内容・画面配置を自動保存
- 起動時にGitHubで新しい正式版を確認

元のフォルダ・ファイルは移動・削除せず、元の場所へのリンクを保存します。
一部のアプリや未保存の文書は、開いている一覧へ表示できません。

## 自動アップデート

1. 起動時に新しい版を確認します。
2. 更新がある場合だけ「アップデートしますか？ はい・いいえ」を表示します。
3. 「はい」でダウンロード・内容の照合・入れ替え・再起動を行います。
4. 再起動後、ダウンロードファイルを自動削除します。

「いいえ」ならそのまま利用できます。設定から手動でも確認できます。
プロジェクトと登録内容は引き継ぎます。更新後の起動に失敗した場合は以前のアプリへ戻します。

このリポジトリには配布案内とアプリ本体のリリースを置いています。開発ソースは非公開で管理しています。
